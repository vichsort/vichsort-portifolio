## About Tera Docs

**Tera Docs** automates contract extraction, docstring parsing, and data schema generation for Python backend frameworks (FastAPI, Flask), producing fast, modern, and accessible developer documentation.

### Highlights

- **Zero Config**: Terminal execution powered by static AST parsing.
- **Flexible Export**: Markdown, interactive HTML, and OpenAPI 3.1 specifications.
- **Type Hint Support**: Rigorous validation and payload mapping.
