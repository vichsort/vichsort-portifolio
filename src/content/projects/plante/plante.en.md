## About the Project

**PlantE** was designed to empower farmers and agronomists with real-time soil health monitoring, crop yield prediction, and automated pest/disease identification using computer vision models alongside **Gemini AI**.

### Key Features

- **AI Diagnosis**: Instant detection of plant disease symptoms from photos taken in the field.
- **Soil Telemetry**: Real-time tracking of moisture, conductivity, and NPK nutrients.
- **Harvest Forecasting**: Predictive algorithms to estimate yield per hectare.

### Tech Stack

- **Frontend**: Vue.js 3, Vite, Responsive CSS
- **Backend / APIs**: [[python|Python]], [[flask|Flask]], Plant.id API, Gemini API
- **Database**: [[postgresql|PostgreSQL]] & [[redis|Redis]]
