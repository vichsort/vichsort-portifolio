## Sobre o Tera Docs

O **Tera Docs** automatiza a extração de contratos, docstrings e esquemas de dados de endpoints Python (FastAPI, Flask) gerando documentação estática moderna, acessível e otimizada para desenvolvedores.

### Destaques

- **Zero Config**: Execução direta no terminal com análise estática de AST.
- **Exportação Flexível**: Markdown, HTML interativo e OpenAPI 3.1.
- **Suporte a Type Hints**: Validação rigorosa e mapeamento de payloads.
